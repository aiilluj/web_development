## 1. Создание виртуального окружения

Была создана папка `MyProject`. Внутри неё создано виртуальное окружение с помощью команды:

```bash
python -m venv venv
```

Появилась папка `venv`. Проверен список глобальных библиотек командой `pip list`.


## 7. Регистрация приложения

После создания приложения, чтобы Django корректно работало, это приложение необходимо зарегистрировать. Регистрируется в конфигурации проекта в файле `settings.py`. Здесь необходимо указать путь к пакету файла конфигурации `app.ru` и указать класс.

1. Открываем файл `MySite/settings.py`.
2. Находим `INSTALLED_APPS`.
3. Добавляем строчку `'news.apps.NewsConfig'`.

![Задание](screen/8.PNG)

*(Рисунок 8 – Регистрация приложения)*

## 8. Создание контроллера

В файле `news/views.py` написаны две функции-контроллера:

```python
from django.shortcuts import render
from django.http import HttpResponse

def index(request):
    print(request)
    return HttpResponse('Hello world')

def test(request):
    return HttpResponse('<h1>Тестовая страница</h1>')
```

`index` – выводит "Hello world" и печатает объект запроса в терминал.
`test` – выводит HTML-заголовок "Тестовая страница".

![Задание](screen/9.PNG)

*(Рисунок 9 – Коды контроллеров index и text)*

## 9. Настройка маршрутов

Первоначальный файл `MySite/urls.py`:

```python
from django.contrib import admin
from django.urls import path

urlpatterns = [
    path('admin/', admin.site.urls),
]
```

При попытке открыть `/news/` получена ошибка 404 – маршрутизатор не знает такой адрес.

![Задание](screen/10.PNG)

*(Рисунок 10 – Добавление маршрутов)*

Создан файл `news/urls.py`:

```python
from django.urls import path
from .views import *

urlpatterns = [
    path('', index),
    path('test/', test),
]
```

![Задание](screen/11.PNG)

*(Рисунок 11 – Создание файла urls.py внутри приложения news)*
